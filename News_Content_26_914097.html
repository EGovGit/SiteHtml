      【霸凌自救指南】我被霸凌了，該怎麼辦？ 要向誰申訴？

      更新日期：民國115年10月xx日
      主要資料來源：勞動部、勞動部職業安全衛生署、教育部、法務部、內政部警政署、臺灣高等檢察署

      若您正在遭受霸凌，請您先記住4件事：保護自己、保留證據、找人求助、提出申訴。本文將為您摘述遭遇霸凌時該如何自救，並依據不同情況（勞工遭遇職場霸凌、學生遭遇校園霸凌、網路霸凌），彙整可採取的因應措施與相關協助資源，幫助您了解如何面對霸凌、尋求適當支持與協助。本文以問答方式摘述計畫內容，實際資格條件、服務項目等，請以主管機關最新的公告為準。

      請注意，本文以問答方式摘述相關內容，實際適用情境，請以主管機關最新的法令規章公告為準。

      目錄
      一. 我被霸凌了，我該怎麼辦？
      二. 遭遇職場霸凌
      三. 遭遇校園霸凌
      四. 遭遇網路霸凌

      一、我被霸凌了，我該怎麼辦？

      (一) 遭遇霸凌，我現在可以做什麼？

      如果您正在遭受霸凌，以下建議供您參考：

      • • 請先確保自身的安全：如有立即的人身危險，請盡速離開現場，並尋求周邊的人協助或報警處理。
      • • 蒐集各項證據，以作為日後申訴用：例如在場證人、監視器畫面、通訊軟體或電子郵件裡的文字/圖片/影像紀錄、合法錄音、就醫紀錄等等。
      • • 記錄人事時地物：詳細記錄霸凌者行為、事件發生的細節、時間及地點，以及周遭在場的其他人。
      • • 尋求情緒支持或求助：不要自己一個人承受，可以向家人或身邊信任的朋友、同事、主管、老師求助。

      (二) 我要怎麼記錄？

      建議每次發生霸凌事件後，儘量設法記錄細節，以下範本供您參考：

      • • 發生的日期、時間及地點
      • • 霸凌者是誰
      • • 對方做了什麼、說了什麼、寫了什麼
      • • 是否有簡訊、電子郵件、截圖、影片、監視器畫面等資料可留存
      • • 這個事件對您的影響有哪些？例如受傷就醫、失眠、焦慮等，若有就醫紀錄請務必保存。

      二、遭遇職場霸凌

       

      💡什麼是職場霸凌？

      • 依據職業安全衛生法第22-1條規定，勞工在「工作場所」執行職務，因其事業單位人員「利用職務或權勢」做出「超過正常管理、合理工作要求的程度」，且「持續」以冒犯、威脅、冷落、孤立、侮辱或其他不當之言詞或行為，導致他人身心健康受到傷害。但情節重大者，不以持續發生為必要。

      💡常見情況有哪些？

      • 以下為舉例說明，實際霸凌事件不限下述類型：
      • • 社交排斥：刻意排擠、忽視或冷落受害者。舉例：在公開場合大聲斥責受害者、故意在LINE群組排除受害者、不讓參與必要之重要會議或事務、不安排正式演出等。
      • • 職務干預：破壞或刻意阻礙被害者的工作，或是利用職務刁難、刻意隱瞞資訊或提供不實資訊。
      • • 權力濫用：以權力欺壓受害者，刻意分配不合理工作目標或與能力明顯不符之工作。
      • • 名譽侵害：刻意散布謠言或揭露隱私。

      💡哪些情況可能屬於正常管理，不屬於職場霸凌？

      • • 雇主或主管可以要求勞工改善工作上的問題，例如多次違反出勤規定、工作表現不佳或不配合合理的工作安排。只要是基於工作需要，以合理、適當的方式進行提醒、糾正或勸導，就屬於正常的管理行為，不代表是職場霸凌。
      • • 是否構成職場霸凌，仍須依實際發生的行為內容、頻率、及造成的影響等情況來判斷。即使不符合職場霸凌的定義，也不代表所有行為都可以被接受。

      💡遭遇職場霸凌，我該怎麼辦？

      • • 記錄人事時地物：建議您詳細記錄霸凌者行為、事件發生的細節、時間及地點，以及周遭在場的其他人。
      • • 蒐集各項證據：例如在場證人、通訊軟體或電子郵件裡的文字、合法錄音、就醫紀錄等，以作為日後申訴用。

      💡遭遇職場霸凌，要向誰申訴？

      • • 當霸凌者是最高負責人：依職業安全衛生法第22-3條，向「地⽅勞⼯行政主管機關」申訴。
      • • 當霸凌者不是最高負責人：依職場霸凌防治措施準則第8條，向「雇主/公司專門受理霸凌申訴之⼈員或單位」提出申訴。

      💡我必須在什麼時間之內提出申訴？

      • • 當霸凌者是最高負責人：
        • 自職場霸凌行為結束後，已超過3年才提出申訴，不予受理。
        • 若職場霸凌事件發生時，勞工還在職，必須於離職之日起1年內提出申訴。但如依前開規定而有較長申訴期限者，依前開規定辦理。
      • • 當霸凌者不是最高負責人：
        • 霸凌者非具權勢地位（例如霸凌者為同事）：自職場霸凌行為結束後，已超過3年才提出申訴，不予受理。
        • 霸凌者具權勢地位（例如霸凌者為主管）：必須於離職之日起1年內提出申訴。但如依前開規定而有較長申訴期限者，依前開規定辦理。

      💡什麼是「具權勢地位」？

      • 在工作場合中，主管或具有管理、指揮、監督權限的人，利用自己的職務或權力，對所管理、指揮或監督的人進行霸凌。

      💡我不清楚要如何申訴，可以向誰諮詢？或有什麼資源可以運用？

      • • 1955勞工諮詢申訴專線：24小時免付費專線，為您提供(法律)諮詢、申訴等服務，或其他相關政府部門服務資訊。
      • • 財團法人法律扶助基金會：若霸凌事件涉及民事賠償、刑事責任或其他法律問題，且被害人有法律扶助的需求，經審核符合申請資格者，即可獲得扶助。

      💡我想知道更多有關職場霸凌防治相關資訊，可以去哪裡查？

      • 如果您想了解更多詳情，像是法令規章、發⽣情境、常見問答等，可參閱勞動部職業安全衛生署職場霸凌防治專區。

      三、遭遇校園霸凌

       

      💡什麼是校園霸凌？

      • 依據校園霸凌防制準則第4條規定，校園霸凌指相同或不同學校校長及教師、職員、工友、學生對學生，於校園內、外所發生之霸凌行為。

        霸凌行為包含一個人或一群人，持續以言語、文字、圖畫、肢體動作、網路等方式，故意貶抑、排擠、欺負、騷擾或戲弄他人，使對方感到不舒服、害怕或被孤立，造成身心理或財產上之損害，或影響正常學習或生活。

      💡常見情況有哪些？

      • 以下為舉例說明，實際霸凌事件不限下述類型：
      • • 肢體霸凌：打、推、踢、撞等身體上的行為，或搶奪財物。
      • • 言語霸凌：恐嚇、嘲笑、貶低、羞辱、取綽號等。
      • • 關係霸凌：孤立、排擠、聯合他人來對付某人等。
      • • 反擊霸凌：不堪被他人霸凌，選擇反擊或去欺負比自己弱小的人，反過來成為霸凌者。
      • • 網路霸凌：散播謠言、刻意引戰、網路跟蹤、留言攻擊、假冒他人網路身分、發布攻擊或詆毀的圖片或影片、散布他人個資等。詳情另可參閱👇【三. 遭遇網路霸凌】

      💡遭遇校園霸凌，我該怎麼辦？

      • • 記錄人事時地物：建議您詳細記錄霸凌者行為、事件發生的細節、時間及地點，以及周遭在場的其他人。
      • • 蒐集各項證據：例如在場證人、通訊軟體或電子郵件裡的文字、合法錄音、就醫紀錄等，以作為日後申訴用。

      💡我要向誰申訴？

      • • 向導師、輔導室或學務處申訴。
      • • 寫信給學校的反映信箱，或撥打專線電話。
      • • 撥打各縣市反霸凌專線電話申訴 (👉點此連結查詢電話號碼：直轄市政府教育局、其他縣市政府教育處)。
      • • 撥打教育部反霸凌專線📞1953。
      • • 至教育部防制校園霸凌專區【留言專區】申訴。

      💡我必須在什麼時間之內提出申訴？

      • • 目前校園霸凌防制準則未規定受害者必須在霸凌事件發生後多久之內提出申訴。不過，當提出申訴後，各階段設有處理及救濟期限，例如對學校不受理或對結果不服時，依法有30日的陳情期限。因此，若您遭遇校園霸凌，建議儘早提出申訴，以免影響後續權益。
      • • 若霸凌事件涉及民事賠償、刑事責任或其他法律問題，相關程序可能有期限限制，建議儘早向警察機關、律師或財團法人法律扶助基金會等專業單位諮詢，或直接向司法單位提出告訴。

      💡我想知道更多有關防制校園霸凌相關資訊，可以去哪裡查？

      • 如果您想了解更多詳情，像是法令規章、發⽣情境、常見問答等，可參閱1953教育部防制校園霸凌專區及教育部認識網路霸凌。

      站外連結之參考文章：
      >>遇到霸凌應該怎麼辦【資料來源：教育部防制校園霸凌專區，民國115年10月】
      >>校園霸凌防制準則【資料來源：法務部 全國法規資料庫，民國113年4月】

      四、遭遇網路霸凌

       

      💡什麼是網路霸凌？

      • 利用網際網路、社群媒體、電子通訊軟體、電子郵件、手機簡訊或其他數位工具等，持續用文字、圖片或影片來辱罵、嘲弄、騷擾、攻擊、威脅特定對象，或散布不實、涉及個人隱私之訊息，造成當事人名譽受損、承受心理壓力、遭受歧視，或其他負面影響。

      💡常見情況有哪些？

      • 以下列舉常見的網路霸凌行為，僅供參考，實際發生的霸凌行為不限於下列類型：
      • • 言語攻擊：持續在論壇或社群媒體中公開侮辱他人、進行惡意留言，或抹黑貼文等。
      • • 通訊干擾：持續傳送大量的騷擾或威脅訊息。
      • • 名譽攻擊：散播不實謠言、發布攻擊或詆毀的圖片或影片、用移花接木的圖樣羞辱他人等。
      • • 身分冒用：未經同意假冒他人網路身分，發布不實消息。
      • • 關係霸凌：反覆對特定對象身邊的親友或有關人士進行攻擊，藉此破壞其人際關係，使其遭到孤立。

      💡遭遇網路霸凌，我該怎麼辦？

      • • 蒐集相關證據：將霸凌者發布的留言、訊息或圖片等內容保存下來，例如透過截圖記錄，以便日後提供相關單位查證。
      • • 阻止持續騷擾：使用社群網站的「封鎖」、「限制留言對象」或「過濾不當字詞」等功能。
      • • 檢舉不當內容：透過網站的檢舉機制反映，要求平臺移除不當內容，或對霸凌者帳號採取限制或停用措施。
      • 🚨 若內容可能涉及犯罪，為有利後續申訴用，建議先保存完整證據後，再進行封鎖或檢舉。

      💡我要向誰申訴？

      • 向「iWIN網路內容防護機構」申訴，您可以進行線上申訴，或撥打📞(02)2577-5118申訴。後續處理流程如下：
      • • 涉及犯罪案件：轉由警察機關處理（由📞110受理）。
      • • 涉及自殺防治：轉由衛生福利部處理（安心專線📞1925）。
      • • 涉及校園霸凌：轉由教育部處理（校園反霸凌專線📞1953）。

      💡我必須在什麼時間之內提出申訴？

      • • 「iWIN網路內容防護機構」主要協助民眾針對網路霸凌內容、個人資料遭洩漏、私密照片或影片遭散布等情形，向相關平臺溝通刪除或隱藏。目前並無規定受害者必須在事件發生後多久之內提出申訴。
      • • 若霸凌事件涉及民事賠償、刑事責任或其他法律問題，相關程序可能有期限限制，建議儘早向警察機關、律師或財團法人法律扶助基金會等專業單位諮詢，或直接向司法單位提出告訴。

      💡我想知道更多有關防制校園霸凌相關資訊，可以去哪裡查？

      • 如果您想了解更多詳情，像是法令規章、常見問答、宣導文章等，可參閱iWIN網路內容防護機構【網路霸凌】及臺灣高等檢察署網路霸凌的刑責。
